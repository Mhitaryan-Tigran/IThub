# КТ № 4 - MySQL. Реализация таблиц

**Версия БД:** 1.0.0.1

## Что создано

- **17 таблиц**
- **58 столбцов** с межтабличными связями
- **20 индексов** (без учёта PRIMARY)
- **5 ролей** с разграничением прав доступа
- **2 процедуры** (Structure_Create, Structure_Re_Create)

## Файлы

### structure_create.sql
Процедура `Structure_Create()` — создаёт все таблицы, индексы и права доступа.

### structure_recreate.sql
Процедура `Structure_Re_Create()` — снимает права, удаляет индексы и таблицы, затем вызывает Structure_Create().

### test_queries.sql
Запросы для проверки структуры и тестирования прав доступа.
