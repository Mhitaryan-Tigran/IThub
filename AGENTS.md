# AGENTS.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Overview
Учебный репозиторий для хранения практических работ IThub. Код пишется на разных устройствах и синхронизируется через GitHub.

## Structure
```
{Subject}/CP{N}/T{M}.py
```
- **Subject** — название предмета (Python, и т.д.)
- **CP{N}** — контрольная/практическая работа №N
- **T{M}.py** — задание №M

## Running Code
```bash
python3 {Subject}/CP{N}/T{M}.py
```

## Language
Комментарии и пользовательский ввод/вывод — на русском языке.
